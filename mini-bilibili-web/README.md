# MiniBili Web

标准的 Vue 3 + TypeScript + Vite 前端项目，已完成日系动漫社区风格首页。

## 技术栈

- Vue 3（Composition API、`<script setup>`）
- TypeScript
- Vite
- 原生 CSS 响应式布局

## 启动

```bash
pnpm install
pnpm dev
```

浏览器访问 `http://localhost:5173`。

## 构建

```bash
pnpm build
pnpm preview
```

## 目录

```text
src/
├── App.vue       首页和交互
├── main.ts       Vue 入口
└── style.css     全局样式
```
